Once the API works, the first thing that tripped me up wasn't code — it was the prompt. Same model, different wording, wildly different results. A few habits I kept after learning the hard way:

## Spell out role and goal

Don't just say "summarize this." Say who you are, who it's for, and how long it should be. The more context, the less the model has to guess.

## Show an example, don't explain

Want a specific format? Paste one example. A single good example beats three paragraphs of description — the model just mimics it.

## Break big tasks apart

Asking it to analyze, polish, and format all at once gets mushy. Split into steps, one job each — the output is far steadier.

## Let it think before answering

For hard questions, add "list your reasoning first, then conclude." It makes fewer mistakes that way.

> Prompting isn't magic — it's stating what you want clearly. If you can't explain it yourself, don't expect the model to guess.
