"AI 到底有哪些类型？"这个问题看似简单，其实答案取决于你站在哪个角度看。普通人关心"我能拿它干什么"，开发者关心"底层是什么模型"，研究者关心"属于哪个技术流派"。这篇把三个角度一次讲清，每类都给代表产品、典型场景和大白话打比方——先看得懂，再谈选型。

> 产品和型号变化极快，但**分类的逻辑是稳定的**。记住"有哪几类、各干什么"，比记住某个具体产品叫什么更有用。

## 一、按交互形态分（普通人直接用的）

这是最直观的一层——你打开一个 App/工具，它长什么样、能帮你做什么。先来一张全景，把普通人日常能碰到的八类 AI 应用一眼看全：

### 1、聊天助手

一问一答的通用对话，写作、翻译、答疑、总结样样能干，是大多数人接触 AI 的第一站。

- **代表**：ChatGPT、Claude、Gemini、豆包、Kimi、文心一言。
- *场景*：写邮件、改简历、翻译、头脑风暴、当搜索引擎问常识。
- *好比*一个啥都懂一点的万能实习生，随叫随到。

### 2、编程 Agent（会自己动手写代码）

不只是给代码建议，而是能读整个项目、跨文件改代码、跑命令、修 bug，多步骤完成任务。

- **代表**：Claude Code、OpenAI Codex、Cursor、GitHub Copilot、Aider、Windsurf / Cline。
- *场景*：从零搭一个功能、批量重构、看懂陌生代码库、按需求自动修改并测试。
- *好比*一个能自己上手改项目的程序员搭子，而不只是背后提词的补全工具。
- 区别：**补全型**（Copilot）边写边提示下一句；**Agent 型**（Claude Code / Codex）你说需求它整段干完。

### 3、AI 搜索 / 答案引擎

边搜网络边总结，直接给答案并附上来源引用，解决传统搜索"给一堆链接自己翻"的痛点。

- **代表**：Perplexity、秘塔搜索、ChatGPT 搜索、Google AI 概览。
- *场景*：查资料、做调研、要带出处的可信答案。
- *好比*一个帮你把十个网页读完、再口述结论并标注引用的研究助理。

### 4、文生图 / 图像生成

用一句话或一张参考图生成图片，也能修图、扩图、换背景。

- **代表**：Midjourney、DALL·E、Stable Diffusion（开源）、谷歌 Imagen / Nano Banana、字节即梦。
- *场景*：海报、插画、概念图、电商图、头像。
- *好比*一个不知疲倦、什么风格都能画的美工。

### 5、文生视频 / 视频生成

从文字或图片生成一段视频，是目前进步最猛的方向之一。

- **代表**：OpenAI Sora、谷歌 Veo、快手可灵（Kling）、Runway、海螺（MiniMax）。
- *场景*：短视频素材、广告分镜、动画概念验证。
- *好比*一个能把你的一句话拍成短片的剧组。

### 6、音频 / 语音

包含语音合成（TTS，文字变声音）、语音识别（ASR，声音变文字）、音乐生成、声音克隆。

- **代表**：ElevenLabs（配音/克隆）、Suno（作曲）、各家 TTS/ASR。
- *场景*：有声书、视频配音、会议转写、做原创音乐。
- *好比*一个能模仿任何嗓音、还能作曲的录音棚。

### 7、智能体 / 编排平台

给普通人或企业搭"会自动干活的 AI 工作流"，少写甚至不写代码。

- **代表**：Coze / 扣子、Dify、n8n、字节等各家 Agent 平台。
- *场景*：搭客服机器人、自动处理表单、把多个 App 串成自动化流程。
- *好比*搭 AI 应用的"乐高积木 + 流水线"，拖拽就能拼。

### 8、多模型客户端 / 聚合网关

自己填一个 API key，就能在一个界面里自由切换多家模型（也能接本地模型）。它不像 ChatGPT/Claude 绑死自家模型，也不像编程 Agent 会动手改文件——纯粹是个"能换发动机"的聊天壳。

- **桌面客户端**：Chatbox（轻量易上手）、Cherry Studio（功能更全，带知识库/MCP）、Jan / LM Studio（偏本地模型）。
- **自托管 Web**：LibreChat、Open WebUI（像自建的 ChatGPT，可多用户）。
- **聚合入口**：Poe（一个入口调多家）、OpenRouter（一个 key 背后接几百个模型）。
- **统一网关**：OpenRouter、LiteLLM——把各家模型统一成同一套接口，"一处配置、随处切换"，前面的客户端和编程 Agent 大多能接它。
- *场景*：想同时用 GPT、Claude、Gemini 做对比，或想接便宜/本地模型省钱，又不想开好几个 App。
- *好比*一台能随手换发动机的车——车壳不变，底下想跑哪家模型都行。

<div class="keypoint">
<div class="lbl">一句话选型</div>
<p>只想聊天问答 → <strong>聊天助手</strong>；想让 AI 帮写代码 → <strong>编程 Agent</strong>；查资料要来源 → <strong>AI 搜索</strong>；做图做视频 → <strong>生成式媒体</strong>；想搭自动化流程 → <strong>智能体平台</strong>；想一个界面切多家模型 → <strong>多模型客户端 / 网关</strong>。</p>
</div>



## 二、按底层能力分（模型类型）

上面是"整车"，这里是驱动它们的"发动机"。同一个聊天 App，背后可能就是不同类型的模型。

### 1、大语言模型（LLM）

以文字为核心，负责理解和生成语言，是当下这波 AI 的绝对主力。

- **代表**：GPT、Claude、Gemini、Llama、DeepSeek、Qwen。
- 几乎所有聊天助手、编程 Agent、搜索引擎底层都是它。
- *好比*一个读完了半个互联网、特别会"说话"的大脑。

### 2、多模态模型

能同时理解并处理文字、图片、音频、视频，不再局限于纯文本。

- **代表**：GPT 系列、Gemini、Claude 的视觉能力。
- *场景*：拍张冰箱照片问"能做什么菜"、看图表写分析、看视频做总结。
- *好比*不仅会读会写，还长了眼睛和耳朵。

### 3、扩散模型（Diffusion）

文生图/视频的主流技术，原理是从一团随机噪点一步步"去噪"还原出清晰画面。

- **代表**：Stable Diffusion、Midjourney、Sora、Veo 背后都是它。
- *好比*把一张打满雪花的电视画面，一点点擦清晰成一幅画。

### 4、语音模型

专攻声音：TTS（合成）、ASR（识别）、声音克隆、音乐生成。

- **代表**：Whisper（识别）、各家 TTS、Suno（音乐）。

### 5、嵌入模型（Embedding）

把文本/图片转成一串数字向量，让"语义相近"变成"数字相近"，是搜索和 RAG 知识库的底座。

- *好比*给每句话标一个"语义经纬度"，意思接近的坐标就挨得近。
- 它不直接和你聊天，却是让 AI"记得住资料、搜得准"的幕后功臣。

### 6、专用模型

为特定领域深度优化的模型：代码模型、生物医药（如蛋白质结构预测）、推荐系统、自动驾驶感知等。

- *好比*全科医生之外的专科大夫，窄但深。

  LLM["大语言模型<br/>文字理解生成"] --> APP1[聊天 · 编程 · 搜索]
  MM["多模态模型<br/>文图音视频"] --> APP2[看图问答 · 视频总结]

## 三、按技术流派分（更学术的分法）

如果往更本质、更学术的层面归类，AI 大致可分为这几派。前面所有产品，几乎都是它们的应用。

### 1、判别式 AI（Discriminative）

做**判断和预测**：分类、识别、打标签。给它输入，它告诉你"是什么"。

- *场景*：人脸识别、垃圾邮件过滤、图像里框出物体、信用评分。
- *好比*一个专门做选择题和判断题的考生。
- 这是深度学习早年（2012 起）的主战场，至今在工业界大量使用。

### 2、生成式 AI（Generative）

**创造新内容**：生成文字、图片、音频、视频、代码。就是现在最火的这波。

- *场景*：ChatGPT 写文章、Midjourney 画图、Sora 生成视频。
- *好比*一个会写作、会画画、会作曲的创作者。
- 和判别式的核心区别：判别式回答"这是什么"，生成式回答"给我造一个"。

### 3、强化学习（Reinforcement Learning）

靠**奖励和惩罚**学习最优策略，在"试错—反馈"中不断变强。

- *场景*：AlphaGo 下围棋、机器人控制、游戏 AI；大模型的 RLHF 调教也用到它。
- *好比*训练宠物——做对给零食，慢慢学会该怎么做。

### 4、符号 / 规则 AI（Symbolic）

早期主流：靠人写死的规则和逻辑推理工作，可解释性强但不灵活。

- *场景*：专家系统、早期的规则引擎、部分知识图谱推理。
- *好比*一本厚厚的"如果……就……"操作手册，照章办事。
- 如今常与神经网络结合（神经符号 AI），取长补短。

<div class="keypoint">
<div class="lbl">流派与应用的对应</div>
<p><strong>判别式</strong>管"认出来"（识别、分类），<strong>生成式</strong>管"造出来"（内容生成），<strong>强化学习</strong>管"学策略"（决策、博弈），<strong>符号 AI</strong>管"讲逻辑"（规则推理）。今天的大模型产品以<strong>生成式</strong>为主，但常融合其他流派。</p>
</div>



## 结语

同一个 AI 产品，可以同时属于三种分类：比如 ChatGPT 是**聊天助手**（交互形态）、底层是**大语言模型 / 多模态模型**（模型类型）、属于**生成式 AI**（技术流派）。分类不是为了背名词，而是帮你在选工具、看新闻、做技术选型时，快速判断"这是哪一类、能解决我的什么问题"。

> 记住那句话——**概念是稳定的，型号是流动的**。产品每月都在换，但"AI 有哪几类、各自擅长什么"这套框架，能用很久。
